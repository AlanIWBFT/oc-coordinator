### Decision 51: host-guided recovery scope

The user chose authoritative recovery only for already-open directory stores. Unopened directories retain upstream additive host-cache hints, accepting temporarily stale activity or pending-request indications. Do not create child stores or initialize a directory runtime merely to confirm those hints.
